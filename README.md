## romm_metrics_exporter ##

A high-performance, ergonomic Rust client for interacting with the ROMM API.

NOTE: This was the author's first attempt at using AI-assisted development,
notably `gemma4:12b` on a Radeon 9070 XT on their local PC.

🚀 Features

 * Type Safety: Fully typed request and response structures using serde.
 * Asynchronous: Built on top of tokio and reqwest for non-blocking I/O.
 * Ease of Use: Minimal boilerplate to get started with authentication and requests.
 * Error Handling: Robust error types that distinguish between network, serialization, and API errors.
 * Customizable: Support for custom headers, timeouts, and proxy settings.
